💡 1. INTRODUCTION & OBJECTIVE
  • Modern endpoint security is hindered by fragmented tools, open LAN vulnerabilities, unverified agent loops, and invasive surveillance methods that compromise privacy.
  • Objective: To develop an integrated, single-port defensive cybersecurity platform that combines real-time endpoint telemetry, agentless remote node auditing, and transparent multi-node fleet management.
  • Key Objective: Design, implement, and validate a hardened Zero-Trust architecture featuring PBKDF2 SHA-256 vault encryption, timing-safe authentication, and strict role immutability.
⚙️ 3. REQUIREMENTS
🖥️ HARDWARE REQUIREMENTS
  • Central SOC Host: Intel Core i5 / Ryzen, 8GB+ RAM, Gigabit Ethernet / 802.11 Wi-Fi.
  • Remote Fleet Endpoints: Windows 10/11 laptops / client nodes on local or extended subnets.
  • Network Telemetry Probes: TCP/3000 (Console), ICMP Prober, TCP Port Auditor (445, 3389, 22).
  • Storage: NVMe/SSD storage for persistent user and audit databases.
💻 SOFTWARE REQUIREMENTS
  • Languages: TypeScript, JavaScript, Python, PowerShell Core.
  • IDEs & Frameworks: VS Code, React 19, Vite, Tailwind CSS v4, Express, TanStack Query.
  • Security & Cryptography: PBKDF2 SHA-256 (100k rounds), Timing-Safe Auth, Dual-Mode Email OTP.
  • Data Store: Persistent JSON File Store (PBKDF2-salted user roster, cryptographic audit ledger).
⚙️ 6. WORKING PRINCIPLE / METHODOLOGY
  • Step 1: Enrolled endpoints stream hardware telemetry (CPU %, RAM, disk storage, suspicious downloads) via authenticated 5s heartbeats.
  • Step 2: Central server normalizes client socket IPs, strictly rejecting spoofed headers (X-Forwarded-For) and SSRF loopback vectors.
  • Step 3: Zero-Trust RBAC engine strictly restricts regular users to SECURITY_ANALYST; Master Admin credentials required for privilege elevation.
  • Step 4: Autonomous threat mitigation triggers remote file quarantine and process termination over secure command queues.
  • Methodology: System Architecture → Modular Implementation → Threat Boundary Hardening → Automated E2E Regression Testing (100% Passed).

⚠️ 2. PROBLEM STATEMENT
  • Existing cybersecurity consoles lack real-time integration between hardware endpoint sensing and centralized analytics, causing blind spots and high overhead.
  • LAN Identity Spoofing: Vulnerable architectures trust client-supplied headers (e.g., X-Forwarded-For) and expose bearer tokens, enabling privilege escalation.
  • Challenge: Guaranteeing low-latency hardware metrics and remote remediation without intrusive surveillance (zero keylogging, zero screen recording) while isolating device telemetry between analysts.
